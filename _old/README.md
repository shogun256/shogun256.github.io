# Starý web (před modernizací)

Tento adresář obsahuje archiv staré verze webu Chata Jestřabí.

## Co je tady
- Původní HTML stránky (index.html, cenik.html, ubytovani.html, kontakt.html, informace.html a další)
- Staré assety (obrazky, stylesheets, javascripts) jsou zatím stále v rootu pod svými původními názvy (`images/`, `stylesheets/`, `javascripts/`, `theme2/`), protože obsahují binární soubory.

## Moderní verze
Moderní verze webu (původně v `test/`) je nyní v rootu:
- `index.html`, `cenik.html`, `ubytovani.html`, `kontakt.html`, `rezervace.html`, `rezervace-dekujeme.html`
- CSS v `css/style.css`, JS v `js/main.js`
- Obrázky moderní verze jsou zatím v `test/assets/` (odkazy v HTML na ně směřují)

## Git historie
Kompletní staré soubory jsou také dostupné v Git historii před modernizačními commity (cca od 2026-07-21 zpět).
